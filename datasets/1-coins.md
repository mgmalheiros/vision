https://ieee-dataport.org/open-access/brazilian-coin-detection-dataset

This is the **regression** dataset, which contains all the images from the classification set (single coins) and other images with several coins and labels, amounting to 6021 images.

The `labelme` annotation format consists of one `json` per image, where the labels can assume one of two types: circle or polygon. A circle label has a center and edge point, and a polygon is a set of points (polygons where used for partial coins).
